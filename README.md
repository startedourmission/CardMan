# 카드맨 (CardMan)

macOS 메시지 앱으로 받은 카드 결제 문자를 읽어서 올해 예산을 얼마나 썼는지 보여 주는 메뉴바 앱입니다.

- 메뉴바에 올해 예산 사용률 표시 (`₩ 65%`, 초과하면 `⚠️ 104%`)
- 원화·해외 결제, 취소·환불 문자 자동 인식
- 일별·월별·분기별·연도별 집계
- 거래별 예산 합계 제외
- 문자로 오지 않는 거래 직접 추가
- CSV 내보내기

문자는 이 Mac 안에서만 읽고, 어디로도 보내지 않습니다.

## 설치

1. [Releases](https://github.com/startedourmission/CardMan/releases)에서 `CardMan-<버전>.dmg`를 받습니다.
2. DMG를 열고 카드맨을 응용 프로그램 폴더로 끌어 놓습니다.
3. 카드맨을 실행합니다.

macOS 14 (Sonoma) 이상, Apple 실리콘과 Intel Mac 모두 지원합니다.

### 전체 디스크 접근 권한

카드맨은 메시지 앱의 데이터베이스(`~/Library/Messages/chat.db`)를 읽어야 해서 전체 디스크 접근 권한이 필요합니다.

1. **시스템 설정 › 개인정보 보호 및 보안 › 전체 디스크 접근 권한**을 엽니다. 카드맨 창의 **설정 열기** 버튼으로 바로 갈 수 있습니다.
2. 목록에서 카드맨을 켭니다. 목록에 없으면 `+` 버튼으로 `/응용 프로그램/CardMan.app`을 추가합니다.
3. 카드맨에서 **새로고침**을 누릅니다.

## 사용법

### 처음 설정

상세 창 아래쪽에서 두 가지를 입력하고 Return을 누릅니다.

- **연간 예산**: 올해 쓸 총 금액 (예: `1800000`)
- **전화번호**: 카드사 문자 발신번호 (기본값 `+8215881688`, KB국민카드 1588-1688)

### 메뉴바

```
₩ 65%
├─ 카드맨 열기
├─ 통계 새로고침
├─ 접근 권한 설정
├─ 올해 총: 1,170,000원 / 1,800,000원
├─ 한도: ██████░░░░ 65%
├─ 잔여: 630,000원
├─ 달러: $123.45
├─ 최근 거래 내역
├─ 12/25 14:30 | 50,000원 | 스타벅스
└─ 종료
```

통계는 앱을 켤 때, 상세 창을 열 때, 그리고 30분마다 다시 읽습니다.

### 예산 합계에서 빼기

상세 창 **거래 내역** 탭에서 **예산 제외** 체크박스를 켜면, 그 거래는 예산 사용액과 기간별 집계에서 빠집니다. 거래를 고르고 스페이스바를 눌러도 됩니다. 거래 자체는 목록에 남고, 체크 상태는 앱을 다시 켜도 유지됩니다.

### 직접 추가한 거래

현금 결제처럼 문자로 오지 않는 거래는 **수동 추가**로 넣고, **수동 거래 관리**에서 지울 수 있습니다.

### CSV 내보내기

**CSV 내보내기**를 누르고 폴더를 고르면 다섯 개 파일이 생깁니다. 엑셀에서 바로 열 수 있게 UTF-8 BOM으로 저장합니다.

- `transactions.csv`: 전체 거래 내역
- `daily.csv`, `monthly.csv`, `quarterly.csv`, `yearly.csv`: 기간별 집계

## 지원하는 문자 형식

| 종류 | 예시 | 처리 |
|---|---|---|
| 국내 승인 | `12,000원` 다음 줄에 가맹점 | 금액 그대로 |
| 가맹점 취소 | 가맹점 이름이 `취소`로 끝남 | 음수로 |
| 취소 완료 | `취소완료 (-12,000원)` | 음수로 |
| 해외 승인 | `123.45(USD)` | 고정 환율로 원화 환산 |

해외 결제 환율은 USD·EUR 1,400원, GBP 1,650원, CNY 180원, JPY 9원으로 고정입니다.

## 데이터 저장 위치

설정과 직접 입력한 내용은 홈 폴더의 JSON 파일에 저장합니다.

- `~/.cardman_config.json`: 연간 예산과 전화번호
- `~/.cardman_manual_transactions.json`: 직접 추가한 거래
- `~/.cardman_excluded_transactions.json`: 예산 합계에서 뺀 거래

문자 내역은 따로 저장하지 않습니다. 새로고침할 때마다 메시지 데이터베이스를 임시 폴더에 복사해서 읽고, 다 읽으면 바로 지웁니다.

## 개발

Xcode 16 이상(Swift 6)이 필요합니다.

```
Sources/CardManCore/   문자 해석, 메시지 DB 읽기, 집계, 저장, CSV (UI 없음)
Sources/CardMan/       SwiftUI 메뉴바 + 상세 창
Tests/CardManCoreTests/
Resources/             Info.plist, 앱 아이콘
scripts/build.sh       빌드, 서명, DMG, 공증
```

```bash
swift test                    # 테스트
scripts/build.sh              # build/CardMan.app 만들기
scripts/build.sh install      # /Applications 에 설치하고 실행
scripts/build.sh dmg          # 서명·공증한 DMG 만들기
```

`build.sh`는 키체인의 Developer ID Application 인증서로 서명합니다. 다른 인증서를 쓰려면 `SIGN_IDENTITY`를 지정하세요. 공증하려면 notarytool 프로필을 한 번 등록해야 합니다.

```bash
xcrun notarytool store-credentials cardman --apple-id <애플 ID> --team-id <팀 ID>
```

버전은 `VERSION` 파일에 있습니다.
