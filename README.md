# 카드맨 (CardMan)

macOS 메시지 앱에서 카드 결제 문자를 자동으로 분석하여 예산 관리를 도와주는 메뉴바 위젯입니다.

## 주요 기능

- iMessage에서 카드 결제 문자 자동 추출
- 실시간 예산 모니터링
- 원화/달러 결제 내역 분류
- 취소/환불 내역 자동 감지
- 일별/월별/분기별/연도별 통계 제공
- 수동 거래 관리
- CSV 파일로 데이터 내보내기

## 설치 방법

### 1. 필수 요구사항
- macOS (앱을 실행하는 Mac에 메시지가 저장되어 있어야 함)
- Python 3.8 이상
- uv (Python 패키지 관리자)

### 2. uv 설치
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### 3. 프로젝트 클론
```bash
git clone <repository-url>
cd CardMan
```

## 실행 방법

### 메뉴바 앱 실행

```bash
uv run menubar_app.py
```

### 상세 분석 앱 실행

```bash
uv run app.py
```

**Tip:** 메뉴바 앱의 '카드맨' 메뉴를 클릭하면 상세 앱이 자동으로 실행됩니다.

## 초기 설정

### 1. 첫 실행시 설정
앱을 처음 실행하면 설정 입력이 필요합니다:

1. **연간 예산 (원)**: 올해 총 예산을 입력 (예: 1800000)
2. **전화번호**: 카드사 문자 발신번호 (예: +8215881688)

### 2. 메시지 접근 권한
macOS에서 메시지 데이터베이스 접근을 허용해야 합니다:
- 시스템 설정 > 개인정보 보호 및 보안 > 전체 디스크 접근 권한
- 터미널 또는 파이썬 실행 파일에 권한 부여

## 사용 방법

### 메뉴바 위젯

메뉴바 아이콘을 클릭하면 다음 정보를 확인할 수 있습니다:

```
₩ 65%                     ← 현재 예산 사용률
├─ 카드맨                  ← 클릭시 상세 앱 실행
├─ 통계 새로고침           ← 최신 데이터로 업데이트
├─ 올해 총: 1,170,000원 / 1,800,000원
├─ 한도: ████████░░ 65%   ← 프로그레스 바
├─ 잔여: 630,000원         ← 쓸 수 있는 남은 금액
├─ 달러: $1,234.56
├─ 최근 거래 내역
├─ 12/25 14:30 | 50,000원 | 스타벅스
├─ 12/24 18:45 | 120,000원 | 올리브영
└─ 종료
```

### 수동 거래 추가

SMS로 오지 않는 거래(현금 결제 등)를 직접 입력:

1. 상세 앱에서 **"거래 수동 추가"** 버튼 클릭
2. 날짜, 금액, 가맹점명 입력
3. 추가 완료 후 자동으로 통계에 반영

### 수동 거래 삭제

잘못 입력한 거래를 삭제:

1. 상세 앱에서 **"수동 거래 관리"** 버튼 클릭
2. 삭제할 거래 선택
3. **"삭제"** 버튼 클릭 후 확인
4. 자동으로 통계 재계산

### CSV 내보내기

거래 내역을 엑셀에서 분석하고 싶을 때:

1. 상세 앱에서 **"CSV 내보내기"** 버튼 클릭
2. 저장 위치 선택
3. 다음 파일들이 생성됩니다:
   - `transactions.csv` - 전체 거래 내역
   - `daily.csv` - 일별 집계
   - `monthly.csv` - 월별 집계
   - `quarterly.csv` - 분기별 집계
   - `yearly.csv` - 연도별 집계

## 데이터 저장 위치

모든 설정과 데이터는 홈 디렉토리에 JSON 파일로 저장됩니다:

- `~/.cardman_config.json` - 예산 및 전화번호 설정
- `~/.cardman_manual_transactions.json` - 수동 입력 거래 내역

**참고:** SMS 거래 내역은 macOS 메시지 앱의 데이터베이스에서 읽어오므로 별도로 저장되지 않습니다.

## 지원하는 결제 유형

### 국내 결제 (KRW)
- 일반 승인: `12,000원`
- 취소/환불: `취소완료 (-12,000원)`

### 해외 결제
- USD: `123.45(USD)` → 환율 1,400원 적용
- EUR: `100.00(EUR)` → 환율 1,400원 적용
- JPY: `1000(JPY)` → 환율 9원 적용
- CNY: `100(CNY)` → 환율 180원 적용
- GBP: `100(GBP)` → 환율 1,650원 적용

## 문제 해결

### 메뉴바 아이콘이 안보여요
- 메뉴바가 꽉 찬 경우 숨겨질 수 있습니다
- 다른 메뉴바 앱을 종료하거나 디스플레이 설정 확인

### 거래 내역이 분석되지 않아요
1. 전화번호가 정확한지 확인
2. 메시지 앱 접근 권한 확인
3. 카드사에서 오는 문자 형식이 지원되는지 확인

### 예산이 메뉴바에 반영되지 않아요
- "통계 새로고침" 메뉴 클릭
- 또는 메뉴바 앱 재시작

### 수동 거래가 메뉴바에 안보여요
- "통계 새로고침" 클릭하여 최신 데이터 로드
- 메뉴바 앱 재시작

## 개발 정보

### 기술 스택
- **메뉴바 앱**: Rumps (Python macOS 메뉴바 프레임워크)
- **상세 앱**: Tkinter (Python GUI)
- **데이터 분석**: Pandas
- **데이터베이스**: SQLite (macOS 메시지 앱 DB)
- **데이터 저장**: JSON

### 프로젝트 구조
```
root/
├── menubar_app.py          # 메뉴바 위젯 메인 파일
├── app.py                  # 상세 분석 앱 메인 파일
├── config.py               # 설정 및 데이터 관리
└── pyproject.toml          # uv 프로젝트 설정
```
